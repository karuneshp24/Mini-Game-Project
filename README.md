# Mini Game Project (C++)

## 📌 Overview
The **Mini Game Project** is a console-based collection of simple games built in **C++** to demonstrate core programming concepts such as loops, arrays, and conditional logic.  
Currently, the project includes a **Tic Tac Toe game**, with plans to extend to other classics like Snake.  

---

## ✨ Features
- Dynamic board display after each move  
- Player turns (X and O)  
- Win/loss detection and draw handling  
- Replay option without restarting the program  
- Clean implementation using loops, arrays, and condition statements
